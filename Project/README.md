# EventSphere X
## Multi-Venue Event Scheduling and Conflict Resolution Engine

### 1. Project Description
EventSphere X is an event scheduling system designed to manage multiple events across different venues. It prevents scheduling conflicts and considers venue capacity and facility requirements.

### 2. Objectives
- Schedule events efficiently.
- Avoid time conflicts.
- Assign suitable venues.
- Compare different scheduling algorithms.
- Improve scheduling performance.

### 3. Algorithms Used
1. Greedy Algorithm
2. Dynamic Programming
3. Brute Force Search
4. Backtracking
5. Merge Sort

### 4. Technologies Used
- Python
- Visual Studio Code

### 5. Project Files
- data.py – Event and venue information
- algorithms.py – Scheduling algorithms
- main.py – Main program and menu
- benchmark.py – Performance testing
- test_data.py – Test datasets
- results.txt – Performance results
- complexity.txt – Complexity analysis
- Output_Screenshots – Program output screenshots

### 6. Testing
The project was tested using:
- Small dataset: 5 events
- Medium dataset: 50 events
- Large dataset: 500 events

### 7. Conclusion
EventSphere X demonstrates different algorithmic approaches to event scheduling. Performance testing helps compare the execution time of scheduling algorithms and understand their efficiency for different dataset sizes.
